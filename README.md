# RNA_DGE_SiHa

A reproducible RNA-Seq Differential Gene Expression (DGE) analysis workflow for SiHa cervical cancer cells (Control vs Treated).

This project implements a structured Snakemake pipeline for processing paired-end RNA-Seq data through quality control, trimming, alignment, and gene quantification.

---

## 📌 Project Overview

This workflow performs:

1. Quality control (FastQC)
2. Adapter trimming
3. Read alignment
4. Gene-level quantification
5. Differential expression preparation

The pipeline is designed for reproducibility, modularity, and scalability.
